# Output Schema

Required core columns are defined in `SKILL.md`. Recommended controlled values:

## Organization Type

Use the most specific applicable value, such as `Nonprofit`, `Private Foundation`, `Public Charity`, `Venture Capital Firm`, `Private Equity Firm`, `Investment Adviser`, `Fund`, `Portfolio Company`, `Association`, `Public Agency`, `Company`, `University/Research Center`, or `Other`.

## Operating Status

Use `Active`, `Inactive`, `Acquired`, `Merged`, `Renamed`, `Dissolved`, `Unclear`, or `Not Applicable`.

## Evidence URL rules

`Primary Evidence URL` is required for included records. `Additional Evidence URLs` may contain semicolon-separated clean URLs. Do not use search result pages, URL shorteners, or unsupported citations. A source must directly support the field it is cited for.

## Allowed missing values

Use `Not publicly located`, `Not applicable`, `Unclear`, or `Needs review`. Do not leave required fields blank and do not use `TBD` after publication.
